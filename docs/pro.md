Frontend Intern Assignment
Project: Simplified CSAT Campaign Builder
Objective
Build a simplified CSAT Campaign Builder. The application should allow a user to configure
a CSAT popup from a Content tab and a Styling tab while showing a live mobile preview that
updates in real time.
What is CSAT?
Customer Satisfaction (CSAT) is a metric used by companies to measure how satisfied
customers are with a product, service, or experience. It is typically collected through a short
feedback form where users rate their experience (for example, on a scale of 1–5 or by
selecting stars) and may optionally leave comments.
In this assignment, you will build a simplified CSAT Campaign Builder that allows users to
configure a feedback popup and instantly preview how it will appear on a mobile device.
The project focuses on:
• Creating a Content configuration page.
• Creating a Styling configuration page.
• Building a real-time mobile preview that reflects all changes made in the Content and
Styling sections.
Note: This is not the complete AppStorys CSAT module. Only the features described in this
assignment are required.

Project Requirements
The project consists of three sections:

1. Content Page
2. Styling Page
3. Live Mobile Preview
   Content Page
   Initial Feedback - Title - Subtitle
   Feedback Page - Rating (Stars or Numbers 1–5) - Dynamic Options (Add/Delete) - Additional Comment Toggle - Submit Button Text
   Thank You Page - Upload Media (Supported formats: PNG, JPG, JPEG, GIF, Lottie) - Title - Subtitle - Button Text
   Styling Page
   Allow users to customize: - Background Color - Title Color - Subtitle Color - Button Color - Button Text Color - Font Size & Font Weight - Border Radius - Button Width & Height - Rating Selected/Unselected Colors
   Live Mobile Preview
   Create a mobile preview on the right side of the screen.
   Every change made in the Content or Styling page must be reflected instantly in the
   preview.
   No Save button or page refresh should be required.
   Functional Requirements
   • Real-time Preview
   • Controlled React Components
   • Dynamic Add/Delete Options
   • Responsive Design
   • Reusable Component Structure
